# Playwright Toolshop — e-commerce test automation

UI test automation project for the practice e-commerce site
[practicesoftwaretesting.com](https://practicesoftwaretesting.com),
built with Playwright and TypeScript using the Page Object pattern.

## Tech stack
- Playwright, TypeScript
- Page Object Model
- GitHub Actions (CI)

## Covered scenarios
- Add a product to the cart

## Getting started
npm install
npx playwright install
npx playwright test
npx playwright show-report

## Project structure
- `tests/` — test specs
- `pages/` — Page Object classes
- `.github/workflows/` — CI pipeline
